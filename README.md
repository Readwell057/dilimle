# Dilimle – Canlı Ses Bölücü

Ses çalarken tek dokunuşla parçalara bölen, tamamen tarayıcıda çalışan web uygulaması.
Dosyalar hiçbir sunucuya yüklenmez.

## Kullanım
1. **Ses dosyası seç** (mp3, wav, m4a, ogg)
2. Sesi çal. Kesmek istediğin yerde **BÖL VE KAYDET**'e bas – ses durmaz, parça listeye eklenir.
3. İstemediğin kısmı atlamak için **BURADAN YENİDEN BAŞLAT (Atla)**.
4. Parça adına dokunarak adını değiştirebilirsin.
5. En altta **Tüm Parçaları ZIP Olarak İndir**.

## GitHub Pages ile yayınlama
1. Bu klasörün içindekileri bir GitHub deposuna yükle (`index.html` ana dizinde olmalı).
2. Depo → **Settings → Pages → Branch: main / (root) → Save**.
3. Birkaç dakika sonra `https://KULLANICIADIN.github.io/DEPOADI/` adresinden aç.
4. Telefonda tarayıcı menüsünden **Ana ekrana ekle** de.
