# Dilimle – Canlı Ses Bölücü

Ses çalarken tek dokunuşla parçalara bölen, tamamen cihazda çalışan uygulama (web + Android APK).

## Kullanım
1. **Ses dosyası seç** (mp3, wav, m4a, ogg)
2. Sesi çal. Kesmek istediğin yerde **BÖL VE KAYDET**'e bas – ses durmaz, parça listeye eklenir.
3. İstemediğin kısmı atlamak için **BURADAN YENİDEN BAŞLAT (Atla)**.
4. Parça adına dokunarak adını değiştirebilirsin.
5. İndirme butonları (APK'da) Kaydet/Paylaş menüsünü açar; oradan "Dosyalar", Drive vb. seçebilirsin.

## APK nasıl oluşur? (otomatik)
1. Bu klasördeki **her şeyi** (gizli `.github` klasörü dahil) GitHub deposuna yükle.
2. Depoda **Actions** sekmesi → "APK Olustur" çalışır (5-8 dakika sürer).
3. Bitince deponun sağındaki **Releases** bölümünden `Dilimle.apk` dosyasını telefona indir ve kur.
   (İlk kurulumda telefon "bilinmeyen kaynaklardan yükleme" izni isteyebilir.)
4. Dosyaları her güncellediğinde APK otomatik yenilenir; yeni sürüm Releases'e eklenir.

## Web olarak yayınlama (isteğe bağlı)
Settings → Pages → Branch: main / (root) → Save.
